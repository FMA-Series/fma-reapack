# ⚠ READ ME FIRST — LÉEME PRIMERO

## ENGLISH

### This package contains TWO files of the SAME plugin

| File | What it is |
|---|---|
| `Effects/ReEQ.jsfx` | **Drop-in replacement for Sai'ke's original ReEQ.** It carries the original file name: install it over the original (or delete the original and keep this one). Your existing projects load it in the original's place, with **every setting preserved**, and it opens with **Sai'ke's original look (Classic)**. **You can delete the original without fear.** |
| `Effects/reeq-fma-edition.jsfx` | The same plugin under its own name. It opens with the FMA house theme, **FMA Solid**. |

The **only** difference between the two files is the look they open with.
Same sound, same controls, same everything else.

- Install one, or **install both** — REAPER tells them apart by file name;
  they never conflict.
- **Always copy the include folders too** — `Effects/reeq-fma-edition-deps/`
  and `Effects/Dependencies/`. Both plugin files share them; without them
  the plugin will not load.
- Full details, button by button: **MANUAL-EN.pdf**.

## ESPAÑOL

### Este paquete contiene DOS archivos del MISMO plugin

| Archivo | Qué es |
|---|---|
| `Effects/ReEQ.jsfx` | **Reemplazo directo del ReEQ original de Sai'ke.** Lleva el nombre del archivo original: instálalo encima del original (o borra el original y quédate con este). Tus proyectos existentes lo cargarán en el lugar del original, **con todos sus ajustes**, y abrirá con **el aspecto original de Sai'ke (Classic)**. **Puedes borrar el original sin temor.** |
| `Effects/reeq-fma-edition.jsfx` | El mismo plugin con nombre propio. Abre con el tema de la casa FMA, **FMA Solid**. |

La **única** diferencia entre los dos archivos es el aspecto con el que abren.
El mismo sonido, los mismos controles, todo lo demás igual.

- Instala uno, o **instala los dos**: REAPER los distingue por el nombre del
  archivo y nunca entran en conflicto.
- **Copia siempre también las carpetas de includes** —
  `Effects/reeq-fma-edition-deps/` y `Effects/Dependencies/`. Ambos archivos
  las comparten; sin ellas el plugin no cargará.
- El detalle completo, botón por botón: **MANUAL-ES.pdf**.
