# ReEQ – FMA Edition

A corrected and extended edition of **ReEQ v1.2.0**, the parametric graphic
equalizer written by **Justin Johnson ("Sai'ke")** for REAPER (JSFX).

ReEQ is one of the most admired equalizer designs in the JSFX world: up to
16 fully parametric bands drawn directly on a spectrum graph, per-band stereo
placement (Stereo / Mid / Side / Left / Right), 14 filter shapes — and an
interface that still feels modern years later. This edition exists because
that design deserved to be finished: a few things in the original code were
never connected, a few were quietly wrong, and its author moved on to other
projects. The FMA Edition completes the pending work as a **tribute to the
original design** — the interface, the workflow and the sound philosophy are
his; the corrections and additions are documented one by one in the header of
the plugin file.

## What the FMA Edition adds and fixes

Everything below is verified against the code; the full per-version log
(fma.1 → fma.20) lives in the header of `Effects/reeq-fma-edition.jsfx`.

**Per-band dynamics, completed.** The original file already carried a
`Band_Dynamic_Range` value that was stored in every session but never used
(audit finding H1). The FMA Edition wires it up: every band can be dynamic,
with its own **DYN** range (−24…+24 dB), **THR** threshold, **ATK**
(0.5–250 ms) and **REL** (5–1000 ms), an ON/OFF switch per band, and a live
visualization on the graph — a translucent fill and a moving curve around
the node, so you see the dynamic gain as it happens.

**HQ rebuilt — ×2 minimum-phase oversampling, no linear phase.** The
original HQ chain leaked the first oversampling image back into the audible
band (measured +32 dB at 23.76 kHz at 48 kHz) while its graph hid the fact.
Early FMA versions experimented with a linear-phase engine; it was removed
by request. HQ is now a clean ×2 oversampling path in the spirit of the
original method: the filters run at twice the sample rate through a
half-band FIR generated by formula at load (125 taps, image rejection
≈ −109 dB stopband / −151 dB folded residue), with only **31 samples of
latency** (PDC-reported, so REAPER compensates it). It works at **every**
sample rate, and the graph draws the filters' true response.

**SILK (HQ only).** A spectral-exciter stage living inside the ×2 path. It
adds only harmonics — the small-signal gain stays at unity, so steady tones
keep their level — with a per-band character: deep lows, defined mids,
expensive highs. At 0 % the stage is skipped entirely and HQ renders
bit-identical. In ECO the SILK control is shown locked, because the stage
physically lives in the oversampled path.

**A finished limiter.** The factory output limiter was a hard clip at
0 dBFS. LIMIT now engages a soft ceiling at **−1 dBFS**: bit-exact
passthrough below a −3 dBFS knee, a smooth curve above it, and a ceiling
that can never be exceeded — with no added latency in either mode.

**Audit fixes from the original code.**
- **B6** — the spectrum "Full" mode summed L+R and read +6 dB hot; it now
  averages like the other modes.
- **B7** — the HQ FIR table was only ever initialised for 44.1/48 kHz;
  selection is now deterministic (superseded by the formula-generated
  half-band, correct at any rate by construction).
- **B8** — at 88.2 kHz and above the original HQ silently behaved as ECO;
  the ×2 path now genuinely runs at every rate.
- **B11** — the frequency mapping was hard-coded to a 22050 Hz Nyquist and
  broke at 48 kHz and above; it is now derived from the real sample rate.
- **B1** — a misspelled variable in the slope dial's fade (cosmetic, fixed).

**A new skin, and six themes.** An FMA house skin (graphite, intense-orange
buttons, translucent node panel with rounded corners — the original panel
design is untouched in spirit) plus six full-window themes: **FMA Fire
Storm, FMA Ice Storm, FMA Sand Storm, FMA Star Rain, FMA Sea Mist** and
**FMA Bronze Wall**, next to the base **FMA Solid** theme and the untouched
**Classic** look. The theme selector is the `GUI:` pill in the bottom bar.
Audio is bit-identical across all of them.

**Starts in ECO, always.** The plugin opens in ECO (light on CPU); HQ is
one click away when you want it.

## Requirements

- REAPER with JSFX support (any modern REAPER).
- No external dependencies beyond the two include files in this package.

## Installation

1. In REAPER: **Options → Show REAPER resource path in explorer/finder**.
2. Open the `Effects` folder inside that path.
3. Copy the contents of this package's `Effects` folder into it, keeping the
   folder structure:
   - `Effects/ReEQ.jsfx` — *the drop-in replacement for Sai'ke's original
     (same file name; opens with the original Classic look). Install it over
     the original and your projects keep working, settings intact.*
   - `Effects/reeq-fma-edition.jsfx` — *the same plugin under its own name
     (opens with the FMA Solid theme). Install either file, or both.*
   - `Effects/reeq-fma-edition-deps/spectrum.jsfx-inc`
   - `Effects/Dependencies/svf_filter.jsfx-inc` *(Sai'ke's original file,
     unmodified)*
4. In REAPER's FX browser, rescan (F5), then insert
   **"JS: ReEQ - Parametric Graphic Equalizer (FMA Edition)"**.
